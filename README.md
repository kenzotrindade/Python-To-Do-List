## 📋 About The Project

This project is a Command Line Interface (CLI) application designed to manage daily tasks. While it looks simple, it is a fundamental exercise in software development to understand **Data Persistence**.

Unlike basic scripts that lose memory when closed, this application reads and writes data to a file (like `.json` or `.txt`), ensuring your tasks are saved between sessions.

---

## ⚙️ Key Features

This tool implements the **CRUD** logic (Create, Read, Update, Delete):

* **➕ Create:** Add new tasks easily to the list.
* **👀 Read:** View all current tasks with their status (Pending/Done).
* **✅ Update:** Mark a specific task as "Completed".
* **❌ Delete:** Remove tasks that are no longer needed.
* **💾 Auto-Save:** The list is automatically saved to a local file.

---

## 🧠 Technical Concepts

This project demonstrates the following Python skills:

* **File I/O (Input/Output):** Opening, reading, and writing files safely using `with open(...)`.
* **Data Structures:** Using Lists and Dictionaries to organize task data.
* **Exception Handling:** Using `try/except` to prevent crashes (e.g., trying to delete a task that doesn't exist).
* **String Formatting:** Displaying a clean and readable list in the terminal.
